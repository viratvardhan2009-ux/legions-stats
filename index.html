Setup & Hosting

A 10-minute, one-time setup

1. Create the repo

Sign in to GitHub (free) and create a new public repository — name it anything, e.g. legions-stats.

Upload two files to the root:

  • index.html — this file
  • data.json — your stats data (already exported below)

2. Enable GitHub Pages

In the repo, go to Settings → Pages. Under "Build and deployment", set:

  • Source: Deploy from branch
  • Branch: main · / (root)

Save. After ~1 minute your site is live at https://<username>.github.io/<repo>/. Share that URL with anyone.

3. Get an edit token

To save changes online, you need a Personal Access Token. Open github.com/settings/tokens → Generate new token (fine-grained).

  • Repository access: only your stats repo
  • Permissions: Contents — Read & write
  • Expiration: up to a year

Copy the token (starts with github_pat_).

4. Connect & edit

Open your live site, click Connect top-right, paste the token plus your username and repo name. The token is stored only in your browser (localStorage) — never sent anywhere except GitHub.

Once connected, the + Add / Edit tab appears. Add matches, edit anything, then click Save. Your changes commit straight to data.json and the public site updates within a minute.

How it works

No database, no server. The site is a static HTML file. Your stats live in data.json inside your GitHub repo. Editing uses the GitHub Contents API to commit the updated JSON. Visitors just read the JSON — no auth needed.

It's free forever within GitHub's generous limits (1GB repo, plenty of API calls).
