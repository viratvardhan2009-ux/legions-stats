Setup & Hosting

A 10-minute, one-time setup

1. Create the repo

Sign in to GitHub (free) and create a new public repository — name it anything, e.g. legions-stats.

Upload two files to the root:

  • index.html — this file
  • data.json — your stats data

2. Enable GitHub Pages

In the repo, go to Settings → Pages. Under "Build and deployment", set:

  • Source: Deploy from branch
  • Branch: main · / (root)

Save. After ~1 minute your site is live at https://<username>.github.io/<repo>/

3. Get an edit token

Go to github.com/settings/personal-access-tokens/new.

  • Resource owner: your username
  • Repository access: only your stats repo
  • Permissions → Contents: Read & write

Copy the token (starts with github_pat_).

4. Connect & edit

Open your live site, click Connect, paste the token plus your username and repo name. The token stays in your browser (localStorage) only.

Once connected, + Add / Edit appears in the nav. The fastest way to record a match is to Upload match report PDF — pick the CricClubs score-card PDF and it auto-fills every batting & bowling figure for review. You can still toggle between Batting and Bowling to enter or tweak stats by hand.

How bowling stats work

For each bowler in a match, enter Overs, Runs conceded, and Wickets. The site computes the bowling average, economy, and strike rate automatically.

Decimal overs are supported (e.g. 3.4 means 3 overs and 4 balls).

Tips

The leaderboards on the dashboard switch between Batting and Bowling with the toggle at the top. Each player card and modal shows both kinds of stats side-by-side.

When adding a new player, you can pick whether they're a batter, a bowler, or both — they'll only appear in the relevant leaderboards.
